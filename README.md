# Odin Landing Page

Лендинг по готовому макету — проект курса [The Odin Project](https://www.theodinproject.com/lessons/foundations-landing-page). Вёрстка на HTML и CSS, раскладка на Flexbox.

**Сайт:** https://makschakof.github.io/odin-landing-page/

## Что тренируется в проекте

- семантическая разметка: `header`, `nav`, `main`, `section`, `blockquote`, `footer`;
- раскладка на Flexbox: шапка «логотип слева — меню справа», две колонки в главном экране, ряд карточек, блок «текст и кнопка»;
- блочная модель: отступы `margin` и `padding`, `box-sizing: border-box`, центрирование через `margin: 0 auto`;
- подключение шрифта Roboto с Google Fonts;
- работа по макету: цвета и размеры шрифтов взяты из задания.
